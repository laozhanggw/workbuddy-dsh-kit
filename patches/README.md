# 关于 11-128 那个补丁：删掉了

这里原本有一个 `patch_11-128.py`，作用是改写 DSH 提示词里的两段话，
好让国内上游不报 `11128 Illegal API invocation from an unapproved channel`。

**它已经被删除，因为它会让所有请求都变成 11128。**

## 实测数据（2026-11-13）

| 时间段 | 网关里那段清洗代码 | 结果 |
|---|---|---|
| 14:00 – 15:19 | 存在，但判断条件写错，**从未生效** | 290+ 次成功，0 失败 |
| 15:19 – 15:53 | 修好条件，**真的开始改写** | 0 成功，172 次失败，**全是 11128** |
| 15:56 之后 | **整段删掉** | 两段原文一起发，200 正常 |

结论：**DSH 原本的措辞是没问题的，是"改写后的措辞"触发了拦截。**

## 所以

- 不要打这个补丁
- 不要在网关里加任何改写提示词的逻辑
- 如果以后再遇到 11128，先想别的方向（账号、IP、出口代理、客户端身份），
  不要动提示词

原来的判断——"这两句话是触发源"——是**错的**。当时那次"打完就好了"是风控时好时坏的巧合，
被当成了因果。
