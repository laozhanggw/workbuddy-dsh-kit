# WorkBuddy 国内额度接入 DSH · 交付包

给同事用的一整套东西：**把腾讯 WorkBuddy 的国内账号额度，接到 DeepSeek Harness（DSH）里当模型用。**

---

## 这个包解决什么问题

DSH 默认要调 DeepSeek 官方 API，要付费。
腾讯的 WorkBuddy（CodeBuddy 国内版）每个账号每天有约 **2 亿 token** 的免费额度。
这套方案在中间加一个本地网关，把 DSH 的请求转成 WorkBuddy 的请求，于是 DSH 就能"白嫖"这笔额度。

```
DSH  →  Magpie（路由）  →  本地网关 :8788  →  WorkBuddy 国内账号  →  你的免费额度
```

## 两个必须知道的限制

### 1. 每账号 2 亿 token / 24 小时，用满就被锁

实测 17 次撞线，全部落在 **198M ~ 200M**，所以上限就是 2 亿。

而且窗口**不是每天零点重置**，是从这个账号这轮第一次被调用起算 24 小时。
所以每个账号的恢复时刻都不一样。

**用满了加积分也没用**，上游直接返回 429，不看余额。

### 2. 积分只能用在别的模型上

- `deepseek-v4.1-flash`：有 2 亿窗口，撞线就停
- `deepseek-v4-pro`、`glm-5.3-flash`、`kimi-*` 等：**没有窗口，纯按积分计费**

所以 flash 用完之后，能继续干活的办法只有：**加账号** 或 **换模型**。
